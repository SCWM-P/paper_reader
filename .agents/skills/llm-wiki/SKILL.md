# 文献卡点伴读与知识 Wiki 构建

目标是帮助用户读懂论文，并积累可跨语境复用的公共领域概念。Wiki 不收录会话话题或实际问答；论文记录承接原问、答复和理解证据。接到“这句或这个公式是什么意思”“基础不够”“我缺少背景知识”“请你系统讲解一下”时使用。表达遵循项目 [CLS](../cls/SKILL.md)；本技能负责知识与记录，不另设语言规则。

## 接续与讲解

- 先用 `paper wiki list` 浏览公共概念和实体；再按当前论文、概念、领域与别名执行 query，回读相关主记录、实际问答和证据。目录由 pyproject.toml 选择，默认 .runtime/llm_wiki，demo 使用 wiki。索引只是入口；记录数量不代表理解程度。
- 首次使用时执行下方 `init` 建空入口。所有记录使用当前[记录契约](references/record-contract.md)，不保留并行格式。
- 定位原句、图、公式及 PDF 物理页。只有术语时，基于可见上下文解释，注明尚未定位的部分。用已知理解范围选择起点；没有相关证据时，暂按“聪明的本科生”解释，专业背景保持 unknown。
- 由当前卡点决定必要先修、粒度和展开程度。缺哪个前提就补哪个，再回到原句；不将一串陌生名词当作解释。系统讲解按用户需求组织，不固定概念数量、追溯深度或统一讲解顺序。
- 数值例子先实际计算，注明教学参数、定义范围和适用边界。类比之后给出准确表述。区分原文、背景、教学例子与推断；教学数字和自拟练习不充当论文实验或用户经历。
- 根据需要提供复述或应用问题。用户可以跳过自测、自述已知、说明遗忘或继续阅读。结束时将解释代回原文，给出返回位置和未解决内容。

## 唯一归属与理解证据

- 公共共识概念（高斯分布、注意力机制、多组学、麦克斯韦方程组）放在 `concepts/c_<UUID>.md`，注明领域、定义范围、来源和共识核实状态。概念定义必须独立于当前论文和会话。来自论文的定义只有具有公共适用性时才可以登记。同名不自动合并；复用前比较定义范围与来源。
- 所有实际原问与答复、论文专属公式、变量及作者定义放在该论文 `assets/reading-record.json` 的 `Q & A`。即使提问涉及公共概念，也不将问答写入概念文件。概念最多通过 question_refs 引用论文问题。没有论文主记录时说明尚未归档，不建立待归属问题库。
- 每次实际学习提问保留一个 `q_UUID4` 和逐字原问。追问独立保存，用关联 ID 归组。相同文字再次提问是新发生；重试同一次保存必须复用原 ID。历史记录标 `legacy_recorded`，不猜测原始措辞或发言时间。
- 原问和实际答复只有一处主记录。实际表现 `reader_evidence` 也随该问题主归属保存；理解判断与依据放在该问答 reader_current。概念文件不保存个人理解状态或表现。
- 提问过、讲解过、自述懂了、真实复述或应用分别记录。`self_report` 和 `inference` 不能证明 `demonstrated_in_scope`。理解判断必须有范围与实际证据；一次表现不代表永久掌握或其他领域的理解。
- 用户说明遗忘、没懂或纠正时，保留旧证据，新增实际反馈与修订原因，再调整当前起点。共识依据的修订不自动改变读者理解状态。

## 保存与回读

用户已授权在伴读中自然更新本地记录，无需逐概念请求登记。首次写记录时读 [记录契约](references/record-contract.md)；更新记录时读 [操作流程](references/workflows.md)。[概念模板](assets/concept-record-template.md) 只供按实际资料填写，不代表用户历史。

先保存原问：`answer` 为 `""`、`answer_at` 为 null、`resolution` 为 `unanswered`。完成实际答复后按同一 ID 补答案与来源。缺论文记录时说明尚未归档；不为保存一问编造四个论文模块。

保存采用基准 SHA256、进程锁和原子替换，不建立历史副本。源文件变化时，重读并合并用户编辑。保存后按 ID 回读，核对完整原问；只有主记录成功才说明已记录。保存失败时不得声称已归档。最后重建派生索引。论文 Q & A 变化后用既有渲染器更新 `note.html`。

从工作区根目录、现有 Python 环境执行：

```bash
paper wiki init
paper wiki list
paper wiki query '当前概念或原问题'
paper wiki query --record 'papers/EXAMPLE/Attention Is All You Need/assets/reading-record.json'
paper wiki reindex
```

list 不接受过滤；默认截断并报告剩余数量，--all 完整列出。query 承接关键词与 --tag、--domain、--type、--id、--record，条件取交集。--id 精确读取概念、实体、实际问题或理解证据。--json 返回机器结果。工具只读正式知识文件与论文记录，不扫描凭据、PDF、ref_repository 或临时资产。浏览器入口为 `paper wiki serve`，直接访问 http://127.0.0.1:8765/。用 `paper wiki status` 查看地址，用 `paper wiki stop` 或 Ctrl+C 关闭；GUI 也有「停止服务」。

`.runtime/` 不进入 Git；云端同步尚未配置。新克隆不会自动携带个人学习历史。论文四模块沿用 AGENTS：AI 草拟 summary 标记 degraded，尚未讨论的 `Q & A` 为 `[]`，`others` 保持普通扩展。实际 Zotero 操作另读 [Zotero SKILL](../zotero/SKILL.md)，本地保存不授予文库写入权限。

本技能承接 Paper Tutor 的卡点讲解、范围区分、理解证据与跨会话接续。教学设计参考 [university-skill](https://github.com/SCWM-P/university-skill) 的必要先修、小数值例子与来源核验思路；本地协议独立编写。
